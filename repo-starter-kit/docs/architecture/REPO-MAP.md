# Repository Map

Customize this map after installing the starter kit.

## Top-level structure

- `src/` — Application source code.
- `docs/` — Project documentation and ADRs.
- `agents/` — Agent rules, personas, and workflows.
- `.github/` — Issue templates, PR template, and workflows.
- `tests/` — Tests when present.
- `scripts/` — Automation scripts when present.

## Key files

- `AGENTS.md` — Repository-wide agent instructions.
- `CLAUDE.md` — Claude/AI-agent quick guide.
- `docs/START-HERE.md` — Onboarding entrypoint.
- `docs/STANDARDS.md` — Mandatory project standards.
- `docs/PROJECT-MEMORY.md` — Decision-oriented project briefing.
- `docs/adr/README.md` — ADR process.

## Protected areas

Update this list for the repo:

- Business/domain data.
- Core state and workflow logic.
- Commerce/payment/billing flows.
- Auth/security/session logic.
- Environment, secret, deployment, dependency, and lock files.
- Generated artifacts and dependencies.
