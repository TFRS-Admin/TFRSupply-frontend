# Agent Personas

Use personas to assign ownership and review responsibility.

## Product Architect

Owns product intent, scope approval, domain behavior, and roadmap tradeoffs.

## Frontend Engineer

Owns approved UI implementation, component architecture, accessibility, and browser behavior.

## Data Engineer

Owns data contracts, migrations, validation, source-of-truth decisions, and data quality.

## Commerce / Integration Engineer

Owns external integrations, commerce flows, pricing, checkout, billing, quotes, orders, and provider APIs.

## QA Engineer

Owns verification plans, regression checks, CI hygiene, screenshots, and QA reporting.

## Documentation Engineer

Owns docs, ADRs, onboarding, templates, and repository operating instructions.

## Security / Platform Engineer

Owns secrets, auth, permissions, environment configuration, deployment, and infrastructure risk.
