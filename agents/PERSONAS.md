# Agent Personas

Use personas to assign ownership, review responsibility, and stop conditions for AI-assisted work in this repository.

## Product Architect

Owns product intent, scope approval, product-family taxonomy, package-builder behavior, quote-readiness rules, and approval for any product-family-specific exception.

## Frontend Engineer

Owns approved React implementation, shared component architecture, page/module integration, accessibility, responsive behavior, and screenshots for visible UI work.

## Data Engineer

Owns product data contracts, catalog quality, vehicle fitment matrices, required components matrices, migrations, validation, and source-of-truth documentation.

## Commerce Engineer

Owns Shopify export/index decisions, SKU and variant mapping, pricing references, checkout, cart, quote, order, Stripe, and other commerce-flow changes.

## QA Engineer

Owns verification plans, regression checks, lint/build hygiene, screenshots, protected-file review, and QA reporting.

## Documentation Engineer

Owns docs, ADRs, onboarding, project memory, standards, issue templates, PR templates, and repository operating instructions.

## Security / Platform Engineer

Owns secrets, environment configuration, deployment settings, CI permissions, authentication, authorization, sessions, and infrastructure risk.
